# 🕰️ TimeTravelAgency — Webapp Immersive

Bienvenue sur le dépôt officiel de **TimeTravelAgency**, une agence de voyage temporelle de luxe. Ce projet a été développé dans le cadre d'un cours sur l'utilisation des outils IA pour le développement web rapide.

## 🚀 Mission
Développer une interface moderne et interactive mettant en scène l'agence et ses 3 destinations phares (Paris 1889, le Crétacé, et Florence 1504) avec des fonctionnalités alimentées par l'IA.

## ✨ Fonctionnalités clés
* **Interface Immersive** : Navigation fluide avec un carousel d'arrière-plan dynamique et des cartes de destinations intégrant des vidéos d'ambiance.
* **Agent Conversationnel (Chronos)** : Un chatbot expert en histoire capable de conseiller les clients sur les époques, les tarifs et la sécurité des sauts temporels.
* **Design Responsive** : Une structure pensée pour une consultation fluide sur desktop comme sur mobile (Mobile-first).
* **Catalogue Temporel** : Présentation détaillée des destinations avec tarifs et contextes historiques.

## 🛠️ Stack Technique & Outils IA
Ce projet a été réalisé en optimisant l'usage de l'intelligence artificielle pour le design et le code :
- **Design & Maquettage** : Planification des features et structure de navigation (Header > Hero > Destinations > Chat).
- **Développement** : HTML5, CSS3 (Tailwind CSS) et JavaScript.
- **Assets** : Visuels et vidéos générés/sourcés pour correspondre à l'identité visuelle de l'agence.

## 📖 Comment utiliser ce projet
1. Clonez le dépôt.
2. Assurez-vous que les fichiers médias (`.jpg` et `.mp4`) sont présents à la racine.
3. Ouvrez `index.html` dans n'importe quel navigateur moderne.
